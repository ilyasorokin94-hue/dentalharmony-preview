# Превью редизайна главной dentalharmony.ru

Тестовая копия главной и внутренних страниц из ветки claude/redesign-v3 (коммит a9a3506) репозитория dentalharmony-site.
Не индексируется (noindex, robots.txt), Метрики нет, форма записи заявки не отправляет.
Ссылки на другие страницы ведут на рабочий сайт dentalharmony.ru.

## /koleso/ — главная с колесом подарков (черновик)

Главная и страница условий акции из ветки claude/project-thread-n4gfss (черновой PR #14 в dentalharmony-site). На рабочий сайт не выложено. Внизу страницы, когда пролистаешь первый экран, выглядывает полкруга большого колеса «Испытайте удачу»; по нажатию колесо открывается целиком. Колесо крутится до заявки, потом форма «Забрать подарок». Заявка никуда не уходит, подарок в превью выбирается случайно.
